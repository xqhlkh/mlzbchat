# AI Chat 部署到甲骨文 Oracle Linux 服务器 — 完整指南

本指南假设你已经有了一台 Oracle Cloud 的 Linux 服务器（Oracle Linux 7/8/9），并且可以通过 SSH 连接上去。

---

## 第一步：连接服务器

在你的电脑上打开终端（Windows 用 PowerShell 或 CMD），用 SSH 连接服务器：

```bash
ssh opc@<你的服务器公网IP>
```

> 如果你创建服务器时用的是 Ubuntu 镜像，用户名是 `ubuntu`。Oracle Linux 默认用户名是 `opc`。
> 第一次连接会提示确认指纹，输入 `yes` 回车。

如果连不上，检查：
- Oracle Cloud 控制台 → 实例详情 → 安全列表 → 确保 TCP 22 端口已开放
- 你用的 SSH 私钥文件是否正确：`ssh -i /path/to/your-key.pem opc@IP`

---

## 第二步：上传项目文件

在你的**本地电脑**上执行（不是在服务器上），把整个 ai-chat 文件夹传到服务器：

```bash
scp -r "D:\dml\ai\mlzb chat\ai-chat" opc@<你的服务器IP>:/home/opc/
```

上传完成后，SSH 重新连上服务器，检查文件是否到位：

```bash
ssh opc@<你的服务器IP>
ls /home/opc/ai-chat/
# 应该能看到：server/  client/  package.json  Dockerfile  deploy-oracle.sh  README.md
```

---

## 第三步：安装 Node.js

Oracle Linux 自带的 Node.js 版本通常太旧，需要手动安装 Node.js 20。

```bash
# 方法一：用 NodeSource 仓库安装（推荐）
curl -fsSL https://rpm.nodesource.com/setup_20.x | sudo bash -
sudo dnf install -y nodejs

# 验证安装
node -v    # 应该显示 v20.x.x
npm -v     # 应该显示 10.x.x
```

如果服务器用的是 `yum` 而不是 `dnf`（OL7 的旧版本），把上面命令里的 `dnf` 换成 `yum`。

---

## 第四步：构建项目

```bash
cd /home/opc/ai-chat

# 4.1 安装后端依赖
cd server && npm install && cd ..

# 4.2 安装前端依赖并构建
cd client && npm install && npm run build && cd ..

# 4.3 配置环境变量
cp server/.env.example server/.env
nano server/.env
```

在 `server/.env` 中填入你的 API Key（至少填一个）：

```env
PORT=3000
HOST=0.0.0.0

# 如果你用 OpenAI 或 DeepSeek、通义千问等兼容接口：
OPENAI_API_KEY=sk-你的key
OPENAI_BASE_URL=https://api.openai.com/v1
OPENAI_MODEL=gpt-4o

# 如果你用 Anthropic Claude：
ANTHROPIC_API_KEY=sk-ant-你的key
ANTHROPIC_MODEL=claude-sonnet-4-20250514

# 搜索默认用 DuckDuckGo（免费），不需要配 Key
SEARCH_PROVIDER=duckduckgo
```

> `nano` 编辑器：编辑完后按 `Ctrl+X`，然后按 `Y`，再按 `Enter` 保存退出。
> 你也可以用 `vi` 或 `vim` 编辑。

---

## 第五步：编译后端 TypeScript

```bash
cd /home/opc/ai-chat/server
npm run build
# 这会把 src/ 目录下的 TypeScript 编译成 dist/ 目录下的 JavaScript
```

## 第六步：开放端口（这一步很多人卡住！）

### 6.1 服务器防火墙

Oracle Linux 默认可能启用了 firewalld：

```bash
# 检查 firewalld 状态
sudo systemctl status firewalld

# 如果正在运行，开放 3000 端口
sudo firewall-cmd --permanent --add-port=3000/tcp
sudo firewall-cmd --reload

# 检查规则是否生效
sudo firewall-cmd --list-ports
```

如果用的是 `iptables`：

```bash
sudo iptables -I INPUT -p tcp --dport 3000 -j ACCEPT
sudo service iptables save
```

### 6.2 Oracle Cloud 安全列表（必须做！）

这是最重要的步骤，很多人忘记这里导致连不上。

1. 打开浏览器，登录 [Oracle Cloud 控制台](https://cloud.oracle.com)
2. 左上角菜单 → **网络** → **虚拟云网络**
3. 点击你的 VCN（虚拟云网络）
4. 点击你的子网（Subnet）下的 **安全列表**（Security List）
5. 点击默认的安全列表（Default Security List）
6. 点击 **添加入站规则**（Add Ingress Rules）：
   - 源类型：**CIDR**
   - 源 CIDR：**0.0.0.0/0**（允许所有 IP）
   - IP 协议：**TCP**
   - 目标端口范围：**3000**
   - 说明：`AI Chat`
7. 点击 **添加入站规则** 保存

## 第七步：测试启动

先手动启动确认一切正常：

```bash
cd /home/opc/ai-chat/server
node dist/index.js
```

你应该看到类似输出：

```
[Server] AI Chat Server running at http://0.0.0.0:3000
[Server] API endpoint: http://0.0.0.0:3000/api
[Server] Configured providers: OpenAI (yes), Anthropic (no)
[Server] Search provider: duckduckgo
```

现在用浏览器访问 `http://<你的服务器公网IP>:3000`，应该能看到 AI Chat 的界面。

如果看不到：
- 确认第六步的安全列表规则已添加
- 确认 `node dist/index.js` 没有报错
- 确认 `client/dist/index.html` 文件存在（如果不存在，重新执行 `cd /home/opc/ai-chat/client && npm run build`）

按 `Ctrl+C` 停掉测试进程。

---

## 第八步：配置 systemd 开机自启

创建 systemd 服务文件，让程序后台运行、崩溃重启、开机启动：

```bash
sudo nano /etc/systemd/system/ai-chat.service
```

写入以下内容：

```ini
[Unit]
Description=AI Chat Server
After=network.target

[Service]
Type=simple
User=opc
WorkingDirectory=/home/opc/ai-chat/server
Environment="PORT=3000"
Environment="HOST=0.0.0.0"
ExecStart=/usr/bin/node /home/opc/ai-chat/server/dist/index.js
Restart=always
RestartSec=3

[Install]
WantedBy=multi-user.target
```

> 注意：`User=` 要填你的实际用户名（`whoami` 查看），`ExecStart` 里的 node 路径用 `which node` 查看。

保存后执行：

```bash
# 重新加载 systemd 配置
sudo systemctl daemon-reload

# 启动服务
sudo systemctl start ai-chat

# 设置开机自启
sudo systemctl enable ai-chat

# 查看状态
sudo systemctl status ai-chat
```

如果状态显示 `active (running)`，就成功了。

常用管理命令：

```bash
sudo systemctl status ai-chat     # 查看运行状态
sudo systemctl restart ai-chat    # 重启服务
sudo systemctl stop ai-chat       # 停止服务
sudo journalctl -u ai-chat -f     # 实时查看日志（Ctrl+C 退出）
sudo journalctl -u ai-chat -n 50  # 查看最近 50 行日志
```

## 第九步：用 Nginx 反向代理（可选，推荐）

如果你想让网站用 80 端口（http）或 443 端口（https），或者想绑定域名，可以加一层 Nginx。

```bash
# 安装 Nginx
sudo dnf install -y nginx

# 创建配置文件
sudo nano /etc/nginx/conf.d/ai-chat.conf
```

写入：

```nginx
server {
    listen 80;
    server_name 你的域名或IP;

    location / {
        proxy_pass http://127.0.0.1:3000;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
        proxy_cache_bypass $http_upgrade;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_buffering off;           # 关闭缓冲，SSE 流式需要
        proxy_read_timeout 86400s;     # 超时设为 24 小时
    }
}
```

保存后：

```bash
# 测试配置
sudo nginx -t

# 启动 Nginx
sudo systemctl start nginx
sudo systemctl enable nginx

# 开放 80 端口
sudo firewall-cmd --permanent --add-port=80/tcp
sudo firewall-cmd --reload
```

同时在 Oracle Cloud 安全列表中放行 TCP 80 端口。
