# AI Chat 部署到甲骨文 Oracle Linux 服务器

## 第一步：连接服务器

```bash
ssh opc@<你的服务器公网IP>
```

## 第二步：克隆项目（推荐用 git）

```bash
cd /home/opc
git clone https://github.com/xghlkh/mlzb-chat.git ai-chat
cd ai-chat
```

也可以用 scp 上传：
```bash
scp -r ai-chat opc@<服务器IP>:/home/opc/
```

## 第三步：安装 Node.js 20

```bash
curl -fsSL https://rpm.nodesource.com/setup_20.x | sudo bash -
sudo dnf install -y nodejs
node -v   # 确认 v20.x.x
npm -v    # 确认 10.x.x
```

## 第四步：安装依赖 + 构建

```bash
cd server && npm install && npm run build && cd ..
cd client && npm install && npm run build && cd ..
```

## 第五步：配置 API Key

```bash
cp server/.env.example server/.env
nano server/.env
```

填入你的 Key，保存（nano 用 Ctrl+X → Y → Enter）。

## 第六步：开放端口

### 6.1 服务器防火墙

```bash
sudo firewall-cmd --permanent --add-port=3000/tcp
sudo firewall-cmd --reload
```

### 6.2 Oracle Cloud 安全列表（必须！）

1. 登录 Oracle Cloud 控制台
2. 菜单 → 网络 → 虚拟云网络
3. 点你的 VCN → 子网 → 安全列表
4. 点默认安全列表 → 添加入站规则
5. 源 CIDR: `0.0.0.0/0`，协议: TCP，端口: `3000`
6. 保存

## 第七步：测试启动

```bash
cd server && node dist/index.js
# 看到 "Server running" 后用浏览器访问 http://服务器IP:3000
# 确认能用后 Ctrl+C 停掉
```

## 第八步：配置 systemd 开机自启

```bash
sudo nano /etc/systemd/system/ai-chat.service
```

写入：
```ini
[Unit]
Description=AI Chat Server
After=network.target

[Service]
Type=simple
User=opc
WorkingDirectory=/home/opc/ai-chat/server
Environment="PORT=3000"
Environment="HOST=0.0.0.0"
ExecStart=/usr/bin/node /home/opc/ai-chat/server/dist/index.js
Restart=always
RestartSec=3

[Install]
WantedBy=multi-user.target
```

启动：
```bash
sudo systemctl daemon-reload
sudo systemctl start ai-chat
sudo systemctl enable ai-chat
sudo systemctl status ai-chat   # 确认 active (running)
```

## 后续更新

```bash
cd /home/opc/ai-chat
git pull
cd client && npm install && npm run build && cd ..
cd server && npm install && npm run build && cd ..
sudo systemctl restart ai-chat
```
